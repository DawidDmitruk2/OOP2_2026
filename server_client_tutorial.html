1 Co to jest Socket?

Socket to jeden koniec rury TCP między dwoma programami. Serwer czeka, klient się podłącza — potem obaj mają swój koniec rury i mogą pisać i czytać.

Klient Serwer
Socket <─── TCP ───> Socket
(twój koniec) (ich koniec)
2 Serwer – minimalny

ServerSocket to "drzwi" serwera — czeka na połączenia. accept() blokuje wątek do momentu gdy ktoś się połączy i zwraca gotowy Socket.

Java 
// Serwer nasłuchuje na porcie 5000
ServerSocket serverSocket = new ServerSocket(5000);

// Blokuje program tutaj i czeka aż ktoś się połączy
Socket socket = serverSocket.accept();

System.out.println("Klient połączony!");
3 Czytanie i pisanie przez socket

Przez socket nie wysyłasz obiektów — wysyłasz tekst linia po linii. BufferedReader służy do odczytu, PrintWriter do zapisu. Parametr true w PrintWriter włącza auto-flush.

Java 
// Odczyt (co klient wysłał)
BufferedReader reader = new BufferedReader(
    new InputStreamReader(socket.getInputStream())
);

// Zapis (co wysyłasz do klienta)
// true = auto-flush, czyli wysyła od razu po println()
PrintWriter writer = new PrintWriter(socket.getOutputStream(), true);

// Odbierz wiadomość (czeka na linię od klienta)
String message = reader.readLine();

// Wyślij odpowiedź
writer.println("Cześć klient!");
4 Pętla odbioru

readLine() zwraca null gdy klient się rozłączy — to jest warunek wyjścia z pętli.

Java 
String message;
while ((message = reader.readLine()) != null) {
    // null oznacza że klient się rozłączył
    System.out.println("Odebrano: " + message);
}
// klient rozłączony
socket.close();
5 Klient – minimalny

Klient łączy się przez new Socket(adres, port). Reszta — strumienie i pętla — jest identyczna jak po stronie serwera.

Java 
// Połącz się z serwerem na localhost port 5000
Socket socket = new Socket("localhost", 5000);

BufferedReader reader = new BufferedReader(
    new InputStreamReader(socket.getInputStream())
);
PrintWriter writer = new PrintWriter(socket.getOutputStream(), true);

// Wyślij wiadomość
writer.println("Hej serwer!");

// Odbierz odpowiedź
String odpowiedz = reader.readLine();
System.out.println("Serwer powiedział: " + odpowiedz);

socket.close();
6 Problem: serwer obsługuje tylko jednego klienta

Bez wątków serwer obsługuje klientów jeden po drugim — drugi czeka aż pierwszy skończy. Rozwiązanie: osobny wątek dla każdego klienta.

⚠️ Bez wątków drugi klient nie może się połączyć dopóki pierwszy nie skończy.
Java 
// ❌ Źle – sekwencyjne, drugi klient czeka
while (true) {
    Socket socket = serverSocket.accept();
    obsluzKlienta(socket);  // blokuje dopóki klient nie skończy
}

// ✅ Dobrze – każdy klient w swoim wątku
while (true) {
    Socket socket = serverSocket.accept();
    ClientThread ct = new ClientThread(socket, this);
    new Thread(ct).start();  // nie blokuje, od razu czeka na kolejnego
}
7 ClientThread – szablon

ClientThread implementuje Runnable — oddziela logikę (run) od zarządzania wątkiem. Każdy klient dostaje własny obiekt z własnymi strumieniami.

Java – ClientThread.java 
public class ClientThread implements Runnable {
    private final Socket        socket;
    private final BufferedReader reader;
    private final PrintWriter   writer;

    public ClientThread(Socket socket) throws IOException {
        this.socket = socket;
        reader = new BufferedReader(
            new InputStreamReader(socket.getInputStream())
        );
        writer = new PrintWriter(socket.getOutputStream(), true);
    }

    @Override
    public void run() {
        String message;
        try {
            while ((message = reader.readLine()) != null) {
                System.out.println("Odebrano: " + message);
                writer.println("Echo: " + message);
            }
            socket.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
8 Broadcast – wysyłanie do wszystkich

Serwer przechowuje listę wszystkich ClientThread. CopyOnWriteArrayList jest bezpieczna wielowątkowo — broadcast() może iterować gdy inny wątek usuwa rozłączonego klienta.

Java – Server.java 
public class Server {
    // CopyOnWriteArrayList – bezpieczna wielowątkowo
    private final CopyOnWriteArrayList<ClientThread> handlers =
        new CopyOnWriteArrayList<>();

    public void broadcast(String message) {
        System.out.println("Serwer odebrał: " + message);
        for (ClientThread ct : handlers) {
            ct.send(message);  // wysyła do każdego klienta
        }
    }

    public void removeHandler(ClientThread ct) {
        handlers.remove(ct);
    }
}
9 Model danych – serializacja przez sieć

Przez socket wysyłasz tylko tekst. Żeby przesłać obiekt, zamieniasz go na string (toMessage) i z powrotem (fromMessage). Locale.ENGLISH zapobiega problemom z przecinkiem vs kropką na różnych systemach.

Java – MyModel.java 
public record MyModel(double x, double y, String label) {

    // Serializacja: obiekt → string do wysłania przez sieć
    public String toMessage() {
        return String.format(Locale.ENGLISH, "%f %f %s", x, y, label);
    }

    // Deserializacja: string z sieci → obiekt
    public static MyModel fromMessage(String message) {
        String[] parts = message.split(" ");
        double x     = Double.parseDouble(parts[0]);
        double y     = Double.parseDouble(parts[1]);
        String label = parts[2];
        return new MyModel(x, y, label);
    }
}
